▌1. 「防護力」不是選配，是標配：👉 軍規防震與防水是你的資料保險
硬碟最怕的就是摔！資料救援動輒上萬，還不一定救得回來。多花幾百塊買有「軍規防震」認證 (MIL-STD 810G) 的硬碟，至少能抵擋日常的意外碰撞。如果常帶出門，有「IPX4 防水」等級的更好，至少不怕被突如其來的飲料或雨水潑到就陣亡。
--
▌2. 「格式」決定你的跨平台自由度：👉 Mac Windows 共用外接硬碟 的秘密
很多硬碟出廠預設是「NTFS」格式，這在 Windows 上暢行無阻，但拿到 Mac 上就變成只能讀不能寫。想在 Mac 和 Windows 之間自由傳輸檔案，一定要把硬碟格式化成「exFAT」。這動作很簡單，但買之前一定要知道，不然會以為買到瑕疵品。
--
▌3. 「傳輸介面」影響你的工作效率：👉 認明 USB 3.2 高速傳輸
現在都 2027 年了，還在用 USB 2.0 傳幾十 GB 的檔案真的會等到天荒地老。請務必選擇「USB 3.2 Gen 1」(跟以前的 USB 3.0 是一樣的東西) 介面的硬碟，傳輸速度快上好幾倍，讓你備份檔案不用再等到睡著。

❓ 外接硬碟 常見問答 (FAQ)

最後，我把這幾天在 PTT 跟 Dcard 爬文時，大家最常問的問題整理出來，幫你破除最後的疑惑：
Q：為什麼我買 2TB 的硬碟，插上電腦卻顯示只有 1.8TB 左右？
A：這是正常的！因為硬碟廠商的計算方式（1000進位）跟電腦作業系統（1024進位）不一樣，容量越大，這個差距會越明顯。不是你買到瑕疵品，大家的都一樣啦！

Q：我要怎麼在 Mac 上使用 Windows 格式(NTFS)的硬碟？
A：最一勞永逸的方法就是備份好資料後，用 Mac 的「磁碟工具程式」把它「清除」並格式化成「exFAT」。這樣一來，不管在 Mac 還是 Windows 都能自由讀寫了。

Q：這些硬碟可以接手機嗎？
A：要看型號！本文提到的 SP A60 和 A66 有支援 Android 手機的 OTG 功能，但你需要另外買一條硬碟專用的 Type-C 傳輸線，並建議先把硬碟格式化成 exFAT。至於 ADATA、Toshiba 和 Seagate 這幾款，官方說明是不支援行動裝置的喔！

Q：硬碟一直讀不到，是不是壞了？
A：先別急！可以先試著換一條傳輸線，或是把 USB 插到電腦主機「後面」的插槽，有時候是前面板供電不足造成的。如果換台電腦也讀不到，那可能真的要準備送修了。
