讀藍光還是燒藍光？COMBO 與燒錄機差在這裡

讀得到藍光，不代表燒得了藍光：混合機型的燒錄只做到 DVD，BD 燒錄機才是讀燒都支援。 規格表的 BD-ROM 6X 是讀取速度，BD-R 6X 才是寫入，兩個數字常被放在同一行，看錯就買錯。只想看片的人，多花錢買到的是一段用不到的功能。

一條 USB 推得動嗎？燒錄時要多接一條

讀取一片 DVD 單線就夠，連續燒錄建議接上輔助電源線。 光碟機的耗電在馬達轉起來與雷射寫入時最高，輕薄筆電的單一埠遇到這種瞬間電流，就會掉線重讀。買之前確認線材是不是 Y 型雙頭，這比埠上標的是 3.0 還是 2.0 實際。

保固給多久？六個月與一年差在機芯

BD 燒錄機的保固從六個月到一年都有，價差通常不到兩百元，建議直接挑一年的。 雷射頭是耗材，連續燒錄的機器大概兩三年就會開始挑片，保固長短等於這段時間的維修成本。桌上型使用、通風好的位置，雷射頭壽命會比塞在筆電包裡長。

買了之後怎麼顧？讓光碟機讀得久的 3 個習慣

光碟拿出來先吹一下灰塵，別用布繞圈擦。 挑片多半是片面細塵與指紋造成，繞圈擦會留下刮痕。由中心往外直線輕推，或直接用吹球吹掉，讀取成功率差很多。

線不要捲著用，接口要插到底。 線材捲成一圈會讓電流不穩，尤其燒錄時最容易掉線。筆電只有一個 USB-C 的話，先確認包裝裡附不附轉接頭，別買回來才發現插不進去。

收納前把片子退出，別讓它留在機器裡。 托盤長時間壓著一片光碟，馬達與齒輪會提早鬆。機器不用時拔掉線、蓋上防塵蓋，雷射頭積塵是讀不到片的主因。

外接光碟機推薦一定要買藍光機嗎？

Q1：藍光片放進去，電腦還是不能播？

機器只負責讀，播放要靠軟體。 Windows 內建的播放器不支援 BD 解碼，要另外裝 PowerDVD 或 Leawo 這類程式，裝好之後就能播。遇到讀得到檔案、畫面卻是黑的，多半是這一關。

Q2：外接光碟機可以接電視或車機嗎？

不行，這類機器是給電腦用的。 它靠 Windows 與 Mac 的驅動認得，車機與電視沒有對應的系統，插上去不會有反應。想在電視上看片，得先把光碟轉成影片檔。

Q3：USB 3.0 真的比 2.0 快嗎？

讀取速度差別不大，供電穩定度差比較多。 光碟本身的物理速度就那樣，USB 2.0 的 480M/s 已經跑得滿；3.0 的好處是供電餘裕，筆電接頭老化時不容易讀到一半掉線。

Q4：讀取時很吵是正常的嗎？

正常，薄機殼的共振就是這樣。 光碟高速旋轉時，外殼跟著震，聲音會比內接式明顯。機器下面墊一塊滑鼠墊或布，聲音會小一截，也比較不會因為震動而讀取失敗。
